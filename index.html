Use Android as a second monitor

This guide helps you prepare an extra Linux display, then stream it to your phone using this website. The website cannot create a Linux monitor or change system settings itself.

Troubleshooting and limitations
  • Only one screen in Linux settings? The extra display has not been created or detected. This website cannot fix that.
  • Phone shows the same desktop? Disable mirroring in Linux display settings and select the second display when sharing.
  • Extra display missing from the browser picker? Check that it is enabled in Linux, try a desktop browser with screen-capture support, and check your desktop's screen-sharing permissions.
  • Phone cannot connect? Check internet access and your connection code. Some networks require a TURN relay configured by the website operator.
  • This page streams video only. Move windows and control applications using your Linux computer, not phone touch.
  • Setup progress is a checklist, not automatic detection. Keep codes private and approve only devices you recognize.

Background: Deskreen's screen-sharing guide also explains the extra-display requirement. Deskreen is a separate app; it is not required for this website's streaming flow.
